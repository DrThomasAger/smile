WindowsRight-click V1CT0R10U5-Regular.ttf and choose Install for all users.
macOSDouble-click V1CT0R10U5-Regular.ttf and press Install in Font Book.
LinuxCopy V1CT0R10U5-Regular.ttf into ~/.local/share/fonts and run fc-cache -f.
Any appRestart the app, then pick V1CT0R10U5 from its font list. Keep line height at 1.15 or more.
GamesLoad the TTF as any font, or use gold-atlas.png with gold-atlas.fnt for the textured gold letters.

On a website, keep the font files beside v1ct0r10u5.css. The class v1ct0r10u5 gives the gold text shown above.

<link rel="stylesheet" href="v1ct0r10u5.css">
<h1 class="v1ct0r10u5">Victory</h1>

Smile prompt language

Prompt language

(: Smile

The positive prompt language for structured prompt engineering. Emoticon faces open and close each named section of a prompt, so long prompts stay modular and maintainable across models.

  1. Open a section with a face and its name, write the instruction inside, and close it with the matching face and the same name.
  2. Nest smaller sections inside larger ones, with a larger face on the outside.
  3. Paste the finished prompt into any model.
(: Role (:
    You are a kind and exact editor.
:) End role :) thank you

Tool

Smile Composer

An outliner in the browser for writing a Smile prompt as nested sections.

  1. Press Enter to edit a row.
  2. Press Right to go into a section and Left to return.
  3. Drag rows to reorder them.
